Cerdas Academy Website Setup Guide

Setup, Installation & Modification Guide

For beginners and non-technical users who want to use, edit, or resell this website.

1. Initial Preparation

  1. Make sure you have Node.js installed (version 16 or above).
    If not, download and install it from the official Node.js website.
  2. Extract or copy the project folder to your computer.
  3. Open the project folder using Terminal or Command Prompt:
    • On Windows: Right-click inside the folder, choose Open in Terminal or Open Command Prompt.
    • On Mac/Linux: Open Terminal, then use the cd command to go to the project folder.

2. How to Install & Run the Website

  1. Install all website dependencies:
    Type the following command in the terminal: 
    npm install
    Wait until the process is finished (requires internet connection).
  2. Run the website in development mode (edit & see changes live):
    npm run dev
    After an address appears (usually http://localhost:5173), open it in your browser.
  3. To create a production/ready-to-upload version:
    npm run build
    The build result will appear in the dist folder. Upload the contents of dist to your hosting.

3. Folder Structure & Important Files

  • index.html: The main page of the website. Edit this file to change the main content/layout.
  • style.css: File for website appearance (colors, fonts, layout). You can edit colors, fonts, etc.
  • main.js: Main script for animations, sliders, statistics, etc.
  • public/: Place your image assets here. Use this folder for all images used on the website.
  • vite.config.js: Build/dev server configuration. Usually you don't need to change this.
  • package.json: List of libraries used. Usually you don't need to change this.

4. How to Modify Website Content

  1. Edit Text/Content:
    Edit the index.html file using Notepad, VSCode, or any text editor. Find the section you want to change (e.g. title, description, testimonials, etc).
  2. Change Images:
    Save your new images in the public/ folder, then update the image links in index.html to point to your new images.
  3. Change Colors/Fonts:
    Edit style.css (e.g. in the :root or @theme section), or use Tailwind classes in index.html.
  4. Edit Animations/Sliders:
    Edit main.js to change animations, sliders, or statistics.
  5. Change Contact/WhatsApp Number:
    Find and replace the WhatsApp number in index.html (for the "Contact Us" button).

5. Uploading to Hosting/Online

  1. Run build with the command npm run build.
  2. Upload all contents of the dist folder to your hosting (can be cPanel, Plesk, or other hosting services).
  3. If your hosting supports Node.js, you can also upload the entire project folder and run npm install & npm run build on the server.

6. Troubleshooting (Common Issues & Solutions)

Q: npm install command gives an error?
A: Make sure Node.js is installed. If you still get errors, try updating Node.js to the latest version.

Q: Website does not appear in the browser?
A: Make sure you have run npm run dev and open the address shown in the terminal (e.g. http://localhost:5173).

7. FAQ (Frequently Asked Questions)

Q: Can I upload this website to regular/shared hosting?
A: Yes, as long as you upload the npm run build result (the contents of the dist folder), not the entire project folder.

Q: Can I change colors, fonts, or images?
A: Absolutely! Edit style.css for colors/fonts, and put your images in the public/ folder.

Q: Can I add new pages?
A: Yes, copy index.html, edit as needed, and add a link to your new page.

8. Support Contact

If you are still confused, please contact the seller or developer of this website for further assistance.

Important Notes:
- Do not delete package.json, vite.config.js, or the node_modules folder.
- If you want to reset, delete the node_modules folder and run npm install again.
- For security, change all contact data before reselling.
